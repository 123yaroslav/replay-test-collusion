Collusion audits test whether agents' actions depend on each other, but agents built on one model act alike without communicating, so these audits accuse honest fleets: mutual information flags 69.3% of games among four honest Claude Haiku agents. Our replay test re-queries each deployed agent every round on the same input with the suspected channel removed, and flags a pair only if its actions depend on each other more than its replays do. If replays are served like the originals, each round's null is exact, and a sequential version is valid at any stopping time. On 550 honest LLM games its fixed-horizon version flags 4.2%. In a procurement auction with a shared pricing vendor, its fixed-horizon version names the true pair in 92.5% of games when the vendor pools confidential costs and flags 1.7% when it uses only public data. A pre-registered replication on fresh games confirmed the sequential version on an instructed positive control. In a pre-registered study of the brief's target environment (Agrawal et al.'s double auction, re-implemented), the sequential version ruled out false-alarm rates of 15% or more. The cartel escaped the pre-registered bet but not a post-hoc statistic, agents departing together from their own replays, confirmed in a fresh pre-registered series (73.3% against 3.3%). It detects what the current channel adds; coordination already stored in instructions or memory escapes it.
