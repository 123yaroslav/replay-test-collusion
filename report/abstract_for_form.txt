Collusion audits test whether AI agents' actions depend on each other, but agents running on one model behave alike without communicating. With four honest Claude Haiku copies playing rock-paper-scissors, a mutual-information test accuses a pair in 69.3% of episodes and the Bonjour et al. rule in 61.3%; on Agrawal et al.'s (2025) logs it flags 8/10 auction runs where sellers could not talk. We propose a replay test for auditors who can query deployed agents: each round, every agent is asked again on what it saw, minus its private channel, and a pair is flagged only if their moves depend on each other more than their replays. This conditional randomization test is exact per round if logged and replayed calls are exchangeable, which a diagnostic supports for the main models; episode-level calibration is checked empirically. Across 550 honest LLM episodes (pre-registered) it flags 4.2% at α = 5%. In a procurement auction it names the pair in 92.5% of episodes where a pricing vendor pools two clients' confidential costs, as alleged in Duffy v. Yardi, and flags 1.7% when the vendor uses only public data. It names 35% of Haiku and 10% of DeepSeek hidden-channel pairs. A sequential version, valid at any stopping time, named more pairs than the fixed test in a pre-registered replication. Coordination written into the agents' instructions is invisible to it by design.
