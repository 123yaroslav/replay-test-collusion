Collusion audits for multi-agent LLM systems test whether agents' actions depend on each other. But agents built on one model share priors and act alike without communicating, so these audits accuse honest fleets: at the 5% level, mutual information flags 69.3% of games among four honest Claude Haiku agents. Our replay test re-queries each deployed agent every round on the same input with the suspected channel removed, and flags a pair only if its actions depend on each other more than its replays do. If replays are served like the originals, the test is exact within each round, and a sequential version stays valid at any stopping time. On 550 honest LLM games its fixed-horizon version flags 4.2%. In a procurement auction with a shared pricing vendor, it names the true pair in 92.5% of games when the vendor pools their confidential costs and flags 1.7% when the vendor uses only public data. In a pre-registered replication on fresh games, the sequential version named an instructed pair in 18/20 games (fixed-length test: 11/20), with 0/40 false alarms. It detects what the current channel adds; coordination already stored in instructions or memory is invisible to it.
