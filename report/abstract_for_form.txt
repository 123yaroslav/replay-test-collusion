Collusion audits for multi-agent LLM systems test whether agents' actions depend on each other. But agents built on one model share priors and act alike without communicating, so these audits accuse honest fleets: mutual information flags 69.3% of games among four honest copies of Claude Haiku. We propose a replay test. In every round the auditor asks each deployed agent again on what it saw, minus the suspected channel, and flags a pair only if its actions depend on each other more than its replays do. The shared model thereby becomes part of the null hypothesis. If replayed calls are served like the originals, the test is exact within each round, and a sequential version keeps its error rate at any stopping time. Over 550 honest LLM games the replay test flags 4.2% at a 5% level. In a procurement auction it names 92.5% of pairs whose pricing vendor pools their confidential costs, while flagging 1.7% of pairs whose vendor uses only public data. A pre-registered replication confirmed the sequential version on fresh games. The test detects what the current channel adds to behaviour; coordination already written into instructions or memory is invisible to it.
