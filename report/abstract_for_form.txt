Collusion audits for multi-agent LLM systems test whether agents' actions depend on each other. Agents that run on one base model share priors and act alike without communicating, so these tests accuse honest fleets: mutual information flags 69.3% of games among four honest Claude Haiku agents, and 8 of 10 published auction runs in which sellers could not talk. We propose a replay test. Every round, the auditor asks each deployed agent again on what it saw, minus the suspected channel, and flags a pair only if its actions depend on each other more than its replays do. The shared model thus becomes part of the null hypothesis. If replayed calls are served like the originals, the test is exact within each round, and a sequential version keeps its false-alarm rate at any stopping time. Across 550 honest LLM games the replay test flags 4.2% at α = 5%. In a procurement auction it names 92.5% of pairs whose pricing vendor pools their confidential costs and flags 1.7% of pairs whose vendor uses only public data, the line drawn in two recent US cases. In a pre-registered replication on fresh games, the sequential version named a secretly coordinating pair in 18/20 games, against 11/20 for the fixed-length test. The test measures what the current channel adds to behaviour: coordination written into shared instructions, or already stored in an agent's memory, is invisible to it.
