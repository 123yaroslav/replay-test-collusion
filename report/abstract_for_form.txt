Collusion audits for multi-agent LLM systems test whether agents' actions depend on each other. But agents built on one model share priors and act alike without communicating, so these audits accuse honest fleets: mutual information flags 69.3% of games among four honest copies of Claude Haiku. We propose a replay test. In every round the auditor re-queries each deployed agent on the same input with the suspected channel removed, and flags a pair only if its actions depend on each other more than its replays do. The shared model thereby becomes part of the null hypothesis. If replayed calls are served like the originals, its false-alarm rate is exact within each round, and a sequential version, which raises an alarm as soon as evidence accumulates, keeps that rate however long the audit runs. Over 550 honest LLM games the replay test flags 4.2% at a 5% level. In a procurement auction where two suppliers follow a common pricing vendor, it names the true pair in 92.5% of games when the vendor pools their confidential costs and flags 1.7% when the vendor uses only public data. In a pre-registered replication on fresh games, the sequential version named more instructed pairs than the fixed-length test and raised no false alarms. The test detects what the current channel adds to behaviour; coordination already written into instructions or memory is invisible to it.
