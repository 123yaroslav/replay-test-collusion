Collusion audits ask whether agents' actions depend on each other. Agents built on one model act alike without communicating, so such audits accuse honest fleets: among four honest Claude Haiku agents, mutual information flags 69.3% of games. We propose a replay test. Each round the auditor asks every deployed agent again what it would do on the same input with the suspected channel removed, and flags a pair only if its logged actions depend on each other more than its replays do. If replays are served like the originals, the null is exact within each round, and a sequential version is valid at any stopping time. On 550 honest LLM games the fixed-horizon version flags 4.2%. In a procurement auction it names the true pair in 92.5% of games when a shared pricing vendor pools confidential costs, and almost never flags a vendor that uses only public data. A pre-registered replication confirmed the sequential version. In a pre-registered study of the brief's target environment (Agrawal et al.'s double auction, re-implemented), the sequential version ruled out false-alarm rates of 15% or more. A cartel in that auction escaped the pre-registered bet. A statistic chosen afterwards caught it, because the colluders left their own replays in the same hours. A fresh pre-registered series confirmed this. The test detects what the current channel adds. Coordination already stored in instructions or memory escapes it. We release the code and the data.
