Collusion audits for multi-agent LLM systems test whether agents' actions depend on each other. But agents built on one model share priors and act alike without communicating, so these audits accuse honest fleets: at the 5% level, mutual information flags 69.3% of games among four honest copies of Claude Haiku. Our replay test re-queries each deployed agent every round on the same input with the suspected channel removed, and flags a pair only if its actions depend on each other more than its replays do. The shared model thereby becomes part of the null hypothesis. If replayed calls are served like the originals, its error rate is exact within each round, and a sequential version stays valid however long the audit runs. On 550 honest LLM games its fixed-horizon version flags 4.2%. In a procurement auction with a shared pricing vendor, it names the true pair in 92.5% of games when the vendor pools their confidential costs and flags 1.7% when the vendor uses only public data. In a pre-registered replication on fresh games, the sequential version named a pair instructed to coordinate in 18/20 games, against 11/20 for the fixed-length test, with 0/40 false alarms on honest games. It detects what the current channel adds; coordination already stored in instructions or memory is invisible to it.
